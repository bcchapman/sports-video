# sports-video

Public facing repository for Sports Video App issue tracking.

## Purpose

This repository is used exclusively for issue intake. Please use the templates below when submitting bug reports or feature requests to ensure we have all the necessary information to reproduce issues and prioritize work.

## How to Report Issues

When creating a new issue, please select the appropriate template below and include all requested information.

---

## 🐛 Bug Report Template

**Title:** [Brief description of the bug]

### Description
A clear and concise description of what the bug is.

### Steps to Reproduce
1. Go to '...'
2. Click on '...'
3. Scroll down to '...'
4. See error

### Expected Behavior
A clear and concise description of what you expected to happen.

### Actual Behavior
A clear and concise description of what actually happened.

### Environment
- Device: [e.g. iPhone 12, Desktop]
- OS: [e.g. iOS 15.0, Windows 10]
- Browser/App Version: [e.g. Chrome 95, App v1.2.3]
- Video Format: [e.g. MP4, MOV]
- Video Resolution: [e.g. 1080p, 4K]

### Screenshots/Videos
If applicable, add screenshots or videos to help explain your problem.

### Additional Context
Add any other context about the problem here (e.g., error messages, console logs, network conditions).

### Priority
- [ ] Critical - Blocks core functionality
- [ ] High - Significant impact on user experience
- [ ] Medium - Affects some users or workflows
- [ ] Low - Minor issue or cosmetic

---

## ✨ Feature Request Template

**Title:** [Brief description of the feature]

### Problem Statement
Describe the problem or pain point this feature would address. What are users unable to do currently?

### Proposed Solution
A clear and concise description of what you want to happen. Include specific functionality or behavior.

### Use Case
Describe who would use this feature and how. Provide concrete examples or scenarios.

### Alternatives Considered
Have you considered any alternative solutions or workarounds? If so, why is this proposal better?

### Impact
Describe the expected impact of this feature:
- How many users would benefit?
- How often would this feature be used?
- What business or user value does it provide?

### Priority
- [ ] Must Have - Critical for product success
- [ ] Should Have - Important but not critical
- [ ] Nice to Have - Would improve experience
- [ ] Low Priority - Future consideration

### Additional Context
Add any other context, mockups, or examples about the feature request here.

---

## Submission Guidelines

1. **Search first**: Before creating a new issue, please search existing issues to avoid duplicates.
2. **One issue per report**: Keep bug reports and feature requests separate.
3. **Be specific**: Provide as much detail as possible using the templates above.
4. **Stay on topic**: Use this repository only for bug reports and feature requests.

Thank you for helping us improve the Sports Video App!
